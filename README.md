# Netheret Support Prototype
## What it is
This is a website for my school project.
## Requirements
- XAMPP (PHP 8.x, MySQL)
- A modern browser
## How to run
1. Copy the `netheret` folder into `C:\xampp\htdocs\`
2. Start Apache and MySQL in XAMPP
3. In phpMyAdmin, create a database called `netheret` and import `sql/schema.sql`
4. Run `http://localhost/netheret/seed_users.php` once, then delete the file
5. Open `http://localhost/netheret/login.php`
